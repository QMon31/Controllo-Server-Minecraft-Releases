## About Voxarium

**Voxarium** is a Windows program for running a **Minecraft Java Edition** server on your own PC from a simple
control panel, without using the command line: from the PC, from a browser and from your phone, at home and away.

- **Server**: start, stop and restart with one click, scheduled restarts with in-game warnings, automatic restart after
  a crash, Eco mode, anti-lag watchdog, live console and chat with the players.
- **Servers**: create a Forge, NeoForge, Fabric, Paper or Vanilla server from scratch, several servers on one PC,
  RAM settings, `server.properties` editor and file manager.
- **Mods and plugins**: info sheet for each mod, Modrinth store with one-click install and mod updates.
- **Backups**: full ZIP backup of the server folder with the expected size, optional copy to Google Drive
  (Google Drive for desktop required), one-click restore.
- **Network**: automatic port opening (UPnP), access from the internet over HTTPS protected by a PIN, Android app
  with notifications.

**Requirements**: Windows 10/11 (64-bit) and Java for the chosen Minecraft version. The panel is available in Italian, English, German, Spanish, French and Portuguese.

**Install**: download `Setup_Voxarium.exe` below (or the
[latest version](https://github.com/QMon31/Voxarium/releases/latest/download/Setup_Voxarium.exe)),
open it and choose **Host** (this PC runs the server) or **Remote** (this PC controls a server on another PC).
Programs already installed update themselves from the "Aggiorna ora" (Update now) bar in the panel.

**Using Linux (Ubuntu / Debian)?** The Linux version has its own release: see the
[Download section](https://github.com/QMon31/Voxarium#download) of the README.

More details in the [README](https://github.com/QMon31/Voxarium#readme).
